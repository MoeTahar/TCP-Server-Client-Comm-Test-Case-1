
# TCP Text Messaging System — Client & Server  
A simple TCP-based text communication system written in Java.  
This project demonstrates socket programming, message exchange, and basic networking concepts for **CST8108 – Networking **.

---

## 📌 Project Overview
This lab implements a **TCP server** and **TCP client** that communicate using Java sockets.  
The server sends messages typed by the user, and the client receives them in real time.

Special commands:
- `goodbye` → closes the client connection  
- `shutdown` → closes the client **and** stops the server  

This project is part of **CET-CS Level 2**, Lab Professor: Mike.

---

## 🧩 Features
- Full TCP communication using Java `Socket` and `ServerSocket`
- UTF message transmission using `DataInputStream` and `DataOutputStream`
- Server accepts one client at a time
- Server operator types messages directly into the console
- Client receives messages continuously until termination
- Graceful shutdown using special keywords
- Clean, readable code structure
